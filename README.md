# MA3632 — Data Mining and AI for Big Data

Lecture notes and workshop notebooks for MA3632/MA3627 Data Mining and AI for Big Data.

## Contents

- `lectures/` — lecture notes (Lec01–Lec12), covering data preprocessing, PCA, k-NN,
  linear/ridge/lasso regression, logistic regression, decision trees, ensembles
  (bagging/random forests/boosting), cross-validation & model interpretation,
  data leakage & pipelines, and graph analytics, including two supplementary
  MA3627 lecture notes.
- `notebooks/` — weekly workshop notebooks (originally developed in Google Colab),
  including two supplementary MA3627 workshops.
